# GuiaFoco — Frontend PoC

## Como executar

1. Abra esta pasta no VS Code.
2. Abra `index.html`.
3. Clique com o botão direito no arquivo e escolha **Open with Live Server** se tiver a extensão Live Server.
4. Se não tiver Live Server, pode abrir o `index.html` diretamente no navegador.

## Estrutura

- `index.html` — telas e estrutura do sistema.
- `css/style.css` — identidade visual, responsividade e acessibilidade.
- `js/app.js` — navegação, cadastro, dados locais, desafios e simulação de intervenção.
- `assets/` — espaço para imagens/ícones futuros.

## O que já está incluído

- Login e modo demonstração.
- Cadastro do responsável.
- Cadastro da criança: idade, série, tempo de tela estimado, preferências, limite diário, horário permitido.
- Dashboard do responsável.
- Perfil da criança.
- Métricas de uso e desempenho.
- Tempo de tela.
- Intervenção/bloqueio visual simulado.
- Microdesafio de alfabetização.
- Preferências e acessibilidade.
- Modo escuro.
- Alto contraste.
- Ajuste de fonte.
- Responsividade para telas menores.
- `localStorage` para manter os dados da PoC.

## Futuro

A estrutura foi pensada para depois substituir os dados locais por chamadas ao backend/API e conectar o módulo de análise por IA.
